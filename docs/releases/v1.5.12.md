### Fixed

- **Duplicate meter unique IDs across multiple VSN config entries** (Reported in #74,
  thanks to Tropie1988 [@Tropie1988](https://github.com/Tropie1988) for the detailed
  report and tested local workaround) — Third-party meters (e.g. Eastron SDM230) report
  a placeholder device ID (`000000-Eastron_1PH-0000`) that is identical on every VSN
  logger. With two config entries, the second meter's entities were rejected with
  "does not generate unique IDs" errors and both meters merged into a single Home
  Assistant device. Meter entity unique IDs and device registry identifiers are now
  namespaced with the logger serial number (which is unique per config entry). A
  one-time config entry migration (v8→v9) rewrites existing meter entities and devices
  in place, so entity IDs, history, and long-term statistics are fully preserved.
