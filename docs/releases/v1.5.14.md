# Release v1.5.14

**Release Date:** Unreleased

**Type:** Minor release — expected outage handling for inverter-powered dataloggers.

## What's Changed

### Added

- **Expected outage handling** (Reported in #79, thanks @piejanssens) — a new option in the integration settings stops the nightly "Cannot connect" repair issue on inverter-powered dataloggers (VSN300 goes dark with the inverter every evening). `Auto-detect`: an outage that begins after the inverter had already stopped producing, with the sun below the daytime threshold, is treated as expected: no repair issue, no device trigger, no recovery script and no recovery notification. If the logger is still unreachable once the sun is above the threshold, normal failure counting starts and you are notified as before. The threshold is learned from your plant's own power-down/power-up sun elevations (last 14 overnight outages, highest value plus 2°; 10° until 3 samples exist) and is visible in the diagnostics download under `expected_outage`. `Fixed time window`: failures inside a daily start/end window (may cross midnight) are expected. Default is `Off`, so nothing changes until you pick a mode. Requires the Home Assistant location to be set for auto-detect.
