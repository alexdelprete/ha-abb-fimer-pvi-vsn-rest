# Release v1.5.6-beta.1

[![GitHub Downloads](https://img.shields.io/github/downloads/alexdelprete/ha-abb-fimer-pvi-vsn-rest/v1.5.6-beta.1/total?style=for-the-badge)](https://github.com/alexdelprete/ha-abb-fimer-pvi-vsn-rest/releases/tag/v1.5.6-beta.1)

**Release Date:** 2026-07-06

**Type:** Beta release - VSN700 leakage-current scale fix and 3rd MPPT channel (String 3) support.

Both changes were reported in #64 (ABB/FIMER TRIO-TM-50.0-400-EU on a VSN700 datalogger).
This is a beta so the changes can be validated on real hardware before a stable release.

## What's Changed

### Added

- **Support for a 3rd MPPT channel (String 3).** Inverters with three independent MPPT
  inputs (e.g. TRIO-TM-50.0-400-EU) now expose String 3 **Voltage**, **Current**, **Power**,
  per-string **Energy**, and **DC-input State** entities — at full parity with String 1 and
  String 2. Previously only String 1 and 2 were mapped, so all String 3 data points were
  missing from Home Assistant.

### Fixed

- **VSN700 leakage current reported 1,000,000× too high.** The VSN700 leakage-current
  points (`IleakInv` / `IleakDC` — the DC-AC and DC-DC leakage sensors) are reported by the
  datalogger in µA, but were being multiplied by 1000 as if they were Amps, yielding values
  a million times too large (e.g. ~11.89 mA shown as ~11,890,000 mA). They are now correctly
  converted µA → mA (÷1000). **This affects all VSN700 installations.**

## Testing focus

Please help validate on real hardware and report back in #64:

1. **Leakage current** (all VSN700 users): the "Leakage DC-AC" / "Leakage DC-DC" sensors
   should now read a sensible value in **mA** (single/low double digits), matching your
   inverter's local Web UI — not millions.
2. **String 3** (3-MPPT inverters, e.g. TRIO-TM-50.0): the new **String 3** Voltage /
   Current / Power (and Energy / State) entities should appear and populate. The String 3
   point names are inferred from the String 1/2 pattern and the vendor register map, so
   on-device confirmation is the main thing this beta is verifying.

## Notes

- The leakage fix is a general correctness fix for **all** VSN700 installations; the value
  of the two leakage sensors will change (downward by 1,000,000×) after updating.
